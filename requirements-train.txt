# 入れてから本ファイルを導入すること（Windows + NVIDIA、例）:
#   pip install torch==2.11.0+cu128 torchvision==0.26.0+cu128 --index-url https://download.pytorch.org/whl/cu128
#   （検証済みバージョン・pin方針の詳細は docs/TORCH_STACK_POLICY.md、
#   手順全体は README「GPU（NVIDIA + CUDA）で学習する場合」を参照）
# 何も指定しなければ CPU 版が入る。
# torch/torchvision はCUDA版wheelが通常PyPIに存在しないため、本ファイルではあえて
# unpinnedのまま維持している（exact pinするとCPU-only環境でのinstallが失敗するため。
# 詳細は docs/TORCH_STACK_POLICY.md 参照）。
